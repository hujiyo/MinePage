单页站：1 个 .html（CSS / JS 请内嵌）；多页站：入口必须是 index.html， 单文件 ≤ 10 MB，每站最多 200 个文件

投稿须知

  • 单页站所有 CSS / JS 请内嵌在 HTML 里
  • 多页站必须包含 index.html 作为入口
  • 单个文件不超过 10 MB
  • 每个站点最多 200 个文件
  • 页面会在沙箱中运行，请勿引用本机资源

发布之后

页面会出现在首页信息流里，其他用户可以搜索、收藏、点赞和评论。
