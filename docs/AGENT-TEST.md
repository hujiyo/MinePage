## D. 工具调用（10 分钟，核心）

### D1 读文件再改（最基本的能力）

**指令（直接复制）：**
```
把 index.html 里 h1 的「欢迎来到我的小站 👋」改成「测试成功 ✅」，其他内容一个字都别动
```

| 检查点 | 预期 |
|---|---|
| 生成中的进度 | 能看到「读文件 index.html」→「改文件 index.html」 |
| 右侧预览 | **自动刷新**，显示「测试成功 ✅」 |
| 最终回复 | 说清楚改了哪个文件、改了什么 |
| 点「代码」标签 → 打开 index.html | 只有 h1 变了，`<style>` 和其他文字原样 |

### D2 新建文件

```
新建一个 about.html，做个简单的「关于我」页面，风格和 index.html 一致
```

| 检查点 | 预期 |
|---|---|
| 左侧文件列表 | 多出 `about.html` |
| 预览 | 能切过去看（或手动打开 `/qwq/admin/page-mwd2t6n1snva/about.html`） |
| 回复 | 说明新建了什么 |

### D3 多文件 + 一次改多个

```
给这个站加一个 assets/style.css，把 index.html 里的内联样式挪过去，然后让 h1 变成蓝色
```

| 检查点 | 预期 |
|---|---|
| 工具调用 | 至少 3 次：读 → 写 css → 改 html |
| 结果 | h1 是蓝色，样式在外部文件里 |

### D4 大文件保护（验证防呆）

先手动造一个大文件：切「代码」标签 → 新建文件 `big.html` → 粘 30000 个字符（随便敲 `a`）→ 保存。
然后：

```
把 big.html 里的所有 a 换成 b
```

| 检查点 | 预期 |
|---|---|
| 回复 | 模型说这个文件太大、整体覆盖会丢内容，**建议你用代码面板手动改**，或者只改别的文件 |
| big.html | **内容没被截断**（还是 30000 字符） |

> 这条是防「模型只读到 20000 字符就照着残缺内容覆盖」的保护，必须验证不被绕过。

## H. 对话模式 vs 编码模式（5 分钟，重点）

这条验证「只回答不编码」是真的做不到，不是靠提示词劝。

| # | 操作 | 预期 |
|---|---|---|
| H1 | 切到**对话**模式 | 胶囊变蓝，标题后挂「· 对话」 |
| H2 | 记下 index.html 当前内容（代码面板里看一眼） | — |
| H3 | 发：`把 index.html 的标题改成「对话模式」` | — |
| H4 | 看进度 | **一次工具调用都没有**（不会出现「读文件」「改文件」） |
| H5 | 看文件 | **一个字都没变** |
| H6 | 看回复 | 说「我改不了文件 / 没有写文件的工具 / 你自己改或切到编码模式」 |
| H7 | 切回**编码**模式，发**同一句话** | 这次会读 → 改，文件真的变了 |

> 这是核心设计：对话模式给模型的工具清单是**空数组**，它物理上没有 `write_file` 可调。
